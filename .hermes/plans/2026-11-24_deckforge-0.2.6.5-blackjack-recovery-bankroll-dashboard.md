# DeckForge 0.2.6.5 — Blackjack recovery + bankroll analytics

## Goal

Fix the repeated-round Blackjack deadlock and turn the bankroll modal into a clear, modern transaction-analytics dashboard. Preserve the current one-file/offline architecture and publish as `0.2.6.5`.

## Acceptance

### Blackjack regression
- A fresh settled round followed by a second round whose dealer has a natural must create a real settlement and `lastRound`; it must not inherit the previous `settled` phase before resolving.
- The real UI flow for a deterministic second-round dealer natural must display one outcome, return to an enabled next-hand state, and log zero runtime errors. Audit must remain valid.

### Bankroll dashboard
- Keep the existing modal entry points, but present a structured dashboard: current balance, recorded income, recorded expenses, net flow, and transaction count/window.
- Categorize every transaction in the saved ledger, including Blackjack/Durak stakes and returns, insurance, doubles, splits, bankruptcy grants, cancellations/refunds, rollbacks, and unknown/future entries.
- Show a clear income-vs-expense comparison, a paired in/out chart for every category, and a balance-over-time chart built from recorded `before`/`after` values. Reconcile net flow to opening/closing balance for the visible transaction window.
- Show recent transactions with timestamp, category, signed amount, and resulting balance. Handle empty/single-entry histories without NaN, broken SVG, or misleading lifetime claims; label the capped recent-history window.
- Use inline accessible SVG/CSS only—no network assets. Respect reduced motion and retain the existing reset-save action.

### Responsive visual QA
- Test the rendered dashboard with realistic transactions spanning every category at phone `390×844`, iPad portrait `834×1194`, and iPad landscape `1194×834`.
- Vision review screenshots at all three sizes. Verify the title, balance, income/expense comparison, every category graph, timeline, and recent transactions; no horizontal overflow, clipping, overlapping, or unusable action buttons.
- Recheck the modal with empty history and long labels. Confirm header and charts remain legible and scroll is internal to the modal.
